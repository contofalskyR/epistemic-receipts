Epistemic Receipts is a corpus of {{claims}} claims generated from public institutional records (legislatures, courts, regulators, archives, scholarly indexes), each linked to the document it came from and labelled with an epistemic status (RECORDED, SETTLED, CONTESTED, OPEN, UNRESOLVABLE, REVERSED, ABANDONED).

It has two layers. The record layer is every claim with its source link and its status as assigned at ingest. The trajectory layer is the {{t2}} claims with a documented status change, {{t1}} of which carry an independent dated source for the change.

Files (Parquet and gzipped CSV): claims, status_history, sources, edges, claim_relations (upstream and identifier-matched links), claim_relations_context (machine-derived context links, not core graph), pipelines. MANIFEST.json gives row counts, SHA-256 checksums, the database snapshot and the git commit; DATA_DICTIONARY.md defines every column; README_DATA.md explains loading in Python, R and DuckDB.

Only corpus tables are included. No user, account, session, key or feedback data; email addresses inside record text are redacted. Upstream licence conditions are recorded per pipeline and per claim (upstreamLicence, upstreamLicenceStatus).

This version replaces the version 1.0.0 PostgreSQL dump.
