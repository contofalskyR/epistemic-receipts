# Upstream licence review

Generated by `scripts/paper/build-licence-review.py` from `docs/paper/upstream-licences.csv` (one row per pipeline, with the page each statement came from; checked 2026-10-24). Dataset licence: CC BY 4.0. *Scientific Data* allows -NC / -SA only when inherited from third-party primary data, and nothing compiled from -ND inputs (`journal-requirements.md`).

**Owner decisions (2026-10-24):** exclude every `restricted` pipeline (UN included), SIPRI, and `cyprus_legislation_v1` (a third-party note of a redistribution ban, until a primary source says otherwise); keep `nc` and `sa` pipelines with the per-row licence columns (`claims.upstreamLicence`, `claims.upstreamLicenceStatus`); keep `unclear` and `not_checked` with a per-row status for this export. `scripts/paper/export.ts` reads the `decision` column: excluded pipelines lose their claims and everything attached, and are listed in `MANIFEST.excludedPipelines`.

Not legal advice: the export ships our own claim text plus upstream identifiers, dates, metadata fields and links. This list records only what each provider (or statute) says.
