# Presubmission enquiry — Scientific Data editorial office

To: Scientific Data editorial office (presubmission enquiry)
Subject: Presubmission enquiry: disclosure for LLM-drafted records in a Data Descriptor

---

Dear Editors,

I am preparing a Data Descriptor for a corpus of 1.76 million claims generated from public institutional records,
each linked to its source document and labelled with an epistemic status, with dated status changes for a subset.
Two parts involved large language models; I would like to confirm the disclosure you require.

1. 5,697 curated trajectories were drafted with LLM assistance. Each status change links a cited source; human
   review is recorded for 21.
2. 1,148 source links for these trajectories were proposed by an LLM with web search and accepted by an automated
   check (page fetched, quoted passage found), not by a person.

We propose to describe both in Methods, naming models and versions, and to flag the affected rows in the data files.
We will also report a human annotation study. Is this disclosure sufficient, or would you
require more?

Yours sincerely,
Robert Contofalsky, Rutgers University
