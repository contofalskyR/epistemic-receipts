# Data Records — facts for the section (from `prisma/schema.prisma` and the database)

Source of truth: `prisma/schema.prisma` (models `Claim`, `ClaimStatusHistory`, `Source`, `Edge`, `ClaimRelation`;
enums `FactStatus`, `RatifyingCommunity`, `ReviewConfidence`) plus the values actually present
(`docs/paper/sql/11_schema_values.sql`, `13_export_counts.sql`, run 2026-10-24). Column-level detail is in
`docs/paper/data-dictionary.md`. This file replaces the v1 draft's Data Records section, whose table and field names
do not match the schema (numbers.md §10 item 14). Facts only; the prose is Robert's.

## Storage

- PostgreSQL 17 + pgvector, schema managed by Prisma (`prisma/schema.prisma`, migrations in `prisma/migrations/`).
- All ids are Prisma `cuid()` strings, except some `ClaimStatusHistory.id` values that are deterministic slugs
  (`<claimId>-<toAxis>-<YYYY-MM-DD>` from `scripts/bulk-promote-corpus.ts`; `csh:trajectory:<slug>:<n>` from seed
  scripts). Ids are opaque; do not parse them.
- No DB-level enums on the epistemic fields: `epistemicAxis`, `toAxis`, `fromAxis` are `text` whose documented
  vocabulary is the Prisma enum `FactStatus`. `community` and `reviewConfidence` are real Postgres enums.

## The five exported tables

Export rule (Phase 3): deleted rows excluded, and rows attached to a deleted claim excluded [13 §13a].

| Table | One row is | Export rows | Table rows | Layer |
|---|---|---:|---:|---|
| `Claim` | one natural-language claim generated from one upstream record (or one curated trajectory) | 1,757,599 | 1,758,118 | record |
| `ClaimStatusHistory` | one dated status row for a claim; the first row per claim is the ingest status, later rows are transitions | 1,821,600 | 1,822,644 | record (first rows) + trajectory (later rows) |
| `Source` | one cited document (upstream record page, retraction notice, statute, court opinion, archival item …) | 1,688,359 | 1,688,359 | provenance |
| `Edge` | one claim → Source link | 1,719,781 | 1,720,395 | provenance |
| `ClaimRelation` | one typed claim → claim link | 4,831,149 | 4,832,590 | links (mostly machine heuristics, see below) |

Relationships (foreign keys in the schema):

- `ClaimStatusHistory.claimId` → `Claim.id` (cascade delete); `ClaimStatusHistory.sourceId` → `Source.id` (nullable;
  the "marker" document for that row).
- `Edge.claimId` → `Claim.id`; `Edge.sourceId` → `Source.id`.
- `ClaimRelation.fromClaimId`, `toClaimId` → `Claim.id` (cascade delete); unique on (from, to, relationType).
- `Claim.parentClaimId` → `Claim.id` (self-reference; 217 corpus claims have a parent [11 §11c]).
- Unique: `Claim.externalId`, `Source.externalId`; `ClaimStatusHistory` (claimId, toAxis, occurredAt) and (claimId, seq).

Of the 1,688,359 Sources, 1,658,927 are referenced by an exported Edge or history row and 29,432 by neither
[13 §13b] (proposal: export only the referenced ones; question 3 in the Phase 2 report).

## `Claim`

- The claim text is `text` (not `claimText`). Generated by code templates in the pipeline's ingester, except the
  curated trajectories (written in the seed scripts) and 16 `book-analysis` claims (LLM) (numbers.md §7).
- `epistemicAxis` (text, nullable): current status, FactStatus vocabulary. Distribution in numbers.md §2: SETTLED
  48.91 %, RECORDED 47.29 %, REVERSED 2.45 %, null 1.32 %, CONTESTED 453, ABANDONED 34, OPEN 4, UNRESOLVABLE 4.
- `verificationStatus` (text, nullable): a **pipeline quality-gate label set by code**, not a human review flag.
  Present values: VERIFIED, PROVISIONAL, DISPUTED, HARD_FACT, DEPRECATED, null. **ACTIVE and UNDER_REVIEW (in the
  v1 draft) do not exist.** What sets each value: numbers.md §1.1.
- `deleted` (boolean): retired records (497 deduplicated roll calls, 22 curated duplicates). Excluded from the export.
- `claimEmergedAt` + `claimEmergedPrecision` (DAY | MONTH | QUARTER | YEAR): the date of the upstream event;
  null for 177,772 corpus claims; 6,630 on 1970-01-01 are placeholders (numbers.md §3.5).
- `ingestedBy` (text): the pipeline tag (187 values; `docs/paper/sources.md`).
- `externalId` (text, unique): pipeline-specific stable key; curated trajectories use `trajectory:<slug>`.
- `metadata` (jsonb): pipeline-specific fields. Most common top-level keys [11 §11d]: `dataset` (1,536,904 claims,
  152 pipelines), `title`, `doi`, `year`, `openalex_id`, `venue`, `cited_by_count`, NARA fields (`naId`,
  `recordGroup`, …), Voteview fields (`congress`, `rollNumber`, `yesCount`, `noCount`, `result`), `corrections`
  (86,984). No fixed schema; the per-key dictionary is in the data-dictionary appendix.
- `humanReviewed`, `reviewedBy`, `reviewedAt`, `reviewConfidence`, `autoApproved`: review signals. `autoApproved`
  = the pipeline's own quality gates passed. `humanReviewed` is set by scripts on 790 of the 833 corpus claims that
  have it; `reviewedBy = 'robert'` on 43 (numbers.md §1.1).
- Legacy, kept for audit, superseded by `epistemicAxis`: `currentStatus` (HARD_FACT 1,732,509 · DISPUTED 23,078 ·
  VERIFIED 2,011 · NEVER_RESOLVES 1; schema comment "DEPRECATED — use epistemicAxis") and `epistemicStatus`
  (null 1,565,628 · approved 131,928 · retracted 26,679 · registered_trial 10,957 · settled_judgment 10,295 ·
  confirmed 9,225 · established 2,886 · contested_dissent 1) [11 §11b].
- `claimType`: INSTITUTIONAL 1,067,400 · EMPIRICAL 685,121 · MEASUREMENT 4,349 · HYBRID 709 · INTERPRETIVE 20
  (schema comment lists four values; MEASUREMENT is undocumented) [11 §11b].
- Not exported: `searchVector` (generated tsvector column).

## `ClaimStatusHistory`

- Columns: `fromAxis` (nullable; null on first rows), `toAxis` (FactStatus vocabulary), `community`
  (RatifyingCommunity), `reason` (text; non-null on every row [11 §11g]), `occurredAt` (**NOT NULL**: the historical
  date of the status, not ingest time), `datePrecision` (DAY | MONTH | QUARTER | YEAR; non-null on every row),
  `sourceId` (nullable; non-null on 30,068 rows), `seq` (1..n per claim; null on 761 rows), `createdAt`.
- **The draft's `axis` and `effectiveDate` do not exist**; the fields are `toAxis`/`fromAxis` and `occurredAt`.
- Row order per claim: `seq`, then `occurredAt`, then `createdAt` (`docs/ORDERING-SEMANTICS-2026-07-08.md`).
- The first row per claim is the ingest status (1,579,633 corpus claims), written by
  `scripts/ingest-auto-trajectories.ts` (only when `claimEmergedAt` is non-null; `occurredAt = claimEmergedAt`) or by
  a seed script. It is not a transition.
- Later rows (241,967) are of four kinds (numbers.md §3.3): 205,182 same-day relabels (schema events, not
  transitions), 18,722 retraction/repeal entry rows, 17,952 row-sourced, 111 other.
- The trajectory layer (numbers.md §3.4): 34,488 claims with a documented status change, 15,777 with an independent
  dated source for it.
- `community` values (RatifyingCommunity): INSTITUTIONAL 1,364,824 · EXPERT_LITERATURE 439,045 · JUDICIAL 16,176 ·
  PUBLIC 1,451 · MARKET 104 (corpus rows).
- Corrections never add rows here (numbers.md §8).

## `Source`

- Columns: `name`, `url` (nullable; non-null on 1,662,805), `publishedAt` (nullable; non-null on 1,134,753),
  `methodologyType`, `ingestedBy`, `externalId`, review fields, `deleted` (no Source is deleted) [11 §11e].
- **The draft's `title` is `name`, and `sourceType` is `methodologyType`.** Values: primary 1,682,278 ·
  derivative 5,962 · opinion 53 · 13 ad-hoc values (secondary 41, guideline 9, review 5, meta-analysis 3,
  regulatory 2, …) (numbers.md §5). The schema comment lists primary | derivative | opinion.
- `ingestedBy` has 319 values (more than the claim pipelines): `enrich*` per-claim tags (131),
  `claude_sourcing_v1` (1,040), `event:*` (3), `eu_parliament_votes_v2` (24,224) (numbers.md §7).

## `Edge`

- **An Edge links a Claim to a Source** (claim ← evidence). It is not a claim-to-claim link; that is `ClaimRelation`.
- `type` values (non-deleted): FOR 1,301,209 · CITES 418,973 · AGAINST 103 · RETRACTS 55 · SUPPORTS 10 ·
  CORRECTED 1 · CONTRADICTS 1 · DISPUTES 1. Schema comment lists FOR | AGAINST | CITES | RETRACTS | CORRECTED
  (SUPPORTS, CONTRADICTS, DISPUTES are undocumented).
- `evidenceType`: EVIDENTIARY 1,690,902 · PROCEDURAL 29,479 · ARGUMENTATIVE 14 [11 §11f].
- Scores are not on Edge: "current score = latest EdgeRevision" (schema comment). `EdgeRevision` (1,558,025 rows)
  is not in the proposed export.

- **3,766,115 of the 4,831,149 exported relations (78 %) record a matching heuristic in `followUpContext.heuristic`**
  (country × year windows, name matches); 12,377 record a `method` (the Phase 7 VOTE_ON / ENACTED_AS batches);
  1,050,001 record no context (CITES, RELATED) [13 §13c]. These are machine-made context links. The AGENTS.md rule
  "cross-references … are editorial work, not algorithmic" was written for case-study CITES edges, and these links
  were made before or outside it. The paper must say what they are (question 2 in the Phase 2 report).
